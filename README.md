# md-check

给 Markdown 文件做**结构自检**：代码块是否闭合、表格列数对不对、任务列表写法标准不标准、标题层级有没有跳级、相对链接是否失效。

**不用装依赖**，一个 Python 文件，Python 3.8+ 就能跑。

## 为什么需要它

Markdown 的问题是**渲染出来才发现坏了**：

| 常见问题 | 渲染后果 |
| --- | --- |
| 代码块少一个 ` ``` ` | 后半篇全变成代码块 |
| 表格某行少一根 ` \| ` | 整张表错位 |
| `- [ ]文字`（缺空格） | 变成一个点 + 字面 `[ ]` |
| 标题从 `##` 直接跳到 `####` | 侧栏大纲层级错乱 |
| 相对链接写错 | 点开是 404 |

**这些都能在写的时候查出来。**

## 用法

```bash
python md-check.py 你的文件.md
```

退出码：`0` = 没结构性问题，`1` = 有问题（可以接进 CI）。

## 输出示例

```
文件：学习编程-完整路线.md
大小：35370 B | 行数：1106 | 字符：19845
✅ 代码块：37 对，闭合正常
✅ 标题：84 个（H1 13 / H2 33 / H3 38 / H4 0）
✅ 表格：检查完毕（结构问题 0 处）
✅ 任务列表：标准 85 条（未打勾 75 / 已打勾 10），不标准 0 条
✅ 加粗配对：检查完毕
✅ 链接：检查完毕（失效相对链接 0 个）

✅ 没有结构性问题

⚠️ 建议关注（1 条）：
   · 重复标题：['### 定位', '### 学到什么程度算够', '### 常见坑']
```

## 检查项

| 检查 | 说明 |
| --- | --- |
| **代码块闭合** | 围栏数量必须是偶数 |
| **标题层级** | 有没有 `H1 → H3` 这种跳级；顺带报重复标题 |
| **表格** | 表头 / 分隔行 / 数据行列数是否一致；Tab 混入会警告 |
| **任务列表** | `- [ ] 文字` 是否标准（缺空格、全角括号都会被抓） |
| **加粗配对** | `**` 是否成对 |
| **相对链接** | 指向的本地文件是否存在 |
| **缩进** | 列表缩进是奇数个空格 |
| **BOM / 行尾空白** | 提示但不当错误 |

**代码块里的内容不参与检查**：里面的 `#` 注释、`|`、`[链接](...)` 都是示例，不该被当成语法。

## 已知取舍

- **只查结构，不查内容**：错别字、语气、事实它不管
- **表格里的转义竖线 `\|` 会正确处理**（这是最容易误报的地方）
- **重复标题只提示不报错**：多语言小节里复用同样的子标题是合理的

## 在 SDD / 文档仓库里用

```yaml
# .github/workflows/md-check.yml
name: md-check
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python md-check.py README.md
```
